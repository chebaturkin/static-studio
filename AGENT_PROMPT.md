# Промпт для агента: Static Studio

Сделай локальную типографскую мастерскую, которая превращает текст, изображения и ссылки в аккуратную статичную страницу. MVP: 3–4 композиции (заметка, портфолио, афиша, мини-справочник), блоки заголовка/текста/изображения/ссылки/разделителя, изменение порядка блоков, импорт локальных изображений, Preview, настройка ширины/цвета/шрифтов, экспорт ZIP с index.html, styles.css и assets, импорт JSON-проекта.

Всё работает в браузере и без CDN в экспортированном результате. Не превращай MVP в Webflow: никакой CMS, аккаунтов, облачной синхронизации и совместного редактирования.

Вайб: маленькая типографская мастерская, тёплая бумага, угольный текст и один акцент. Подбери необычную пару с кириллицей: humanist serif для заголовков и спокойный grotesk/mono для интерфейса. Тонкие линии, большие поля, асимметричная сетка и маленький монохромный знак из геометрических линий. Никаких градиентов, стеклянных карточек, мета-бейджей, bento, pill-кнопок, огромного hero и кнопки «Начать». Главный результат должен быть понятен раньше панели настроек. README содержит GIF или скринкаст, пример экспорта и инструкцию открыть index.html без сборки.


## Общие правила

- Сделай рабочий MVP как статический сайт для GitHub Pages.
- Не используй API-ключи, платные сервисы, обязательный backend, серверную базу данных, авторизацию или внешнюю AI-модель.
- Пользовательские файлы обрабатывай только в браузере; данные не отправляй на свой сервер.
- Если внешний URL упирается в CORS или лимиты, оставь полноценный локальный сценарий через ZIP, JSON или CSV.
- Сначала зафиксируй дизайн-систему и пользовательский сценарий, затем пиши код.
- Запрещены градиенты, glassmorphism, декоративные баблы, pill-кнопки, бесконечные карточки, bento-сетки, огромный hero-блок, CTA ради CTA и типичный AI/SaaS-дашборд.
- Не используй Inter, Roboto, Open Sans и похожие шаблонные пары как главный визуальный голос. Выбирай собственные шрифты с хорошей кириллицей и локальными fallback.
- Проверь desktop/mobile, клавиатуру, focus, reduced motion, пустые состояния и понятные ошибки.
