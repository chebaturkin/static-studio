# Static Studio

Сделай локальную типографскую мастерскую, которая превращает текст, изображения и ссылки в аккуратную статичную страницу. MVP: 3–4 композиции (заметка, портфолио, афиша, мини-справочник), блоки заголовка/текста/изображения/ссылки/разделителя, изменение порядка блоков, импорт локальных изображений, Preview, настройка ширины/цвета/шрифтов, экспорт ZIP с index.html, styles.css и assets, импорт JSON-проекта.

Основное задание для агента: [AGENT_PROMPT.md](./AGENT_PROMPT.md).
