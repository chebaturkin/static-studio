# Static Studio

static studio — локальная типографская мастерская для небольших статичных страниц. Здесь можно собрать текст, изображения и ссылки, проверить страницу рядом с редактором и скачать готовый набор файлов.

![демо Static Studio: редактор, предпросмотр и экспорт](./docs/demo.gif)

## что здесь можно сделать

- выбрать основу: заметку, портфолио, афишу или мини-справочник;
- собрать страницу из заголовков, текста, изображений, ссылок и разделителей;
- менять порядок блоков кнопками, клавиатурой или перетаскиванием;
- настроить ширину, цвета и шрифты страницы;
- загрузить изображение с устройства — оно останется внутри проекта;
- сохранить проект в JSON или скачать самодостаточный ZIP;
- продолжить работу после перезапуска, если браузер разрешает `localStorage`.

файлы обрабатываются в браузере и никуда не отправляются. внешние изображения по HTTPS сохраняют ссылку на сеть и не копируются в ZIP. локальные PNG, JPEG, GIF, SVG, WebP и AVIF до 10 МБ можно упаковать в папку `assets/`.

## попробовать локально

откройте корневой `index.html` в современном браузере. сборка, сервер, аккаунт и CDN не нужны. чтобы проверить экспорт, откройте [пример страницы](./examples/export/index.html) — рядом с ним лежат только стили и локальная картинка.

горячие клавиши:

- `Cmd/Ctrl + Z` — отменить действие;
- `Cmd/Ctrl + Shift + Z` или `Cmd/Ctrl + Y` — повторить действие;
- `Alt + ↑/↓` — переместить выбранный блок.

## json и zip

1. нажмите **экспортировать JSON**, чтобы сохранить структуру проекта;
2. нажмите **импортировать проект**, чтобы продолжить работу из JSON;
3. нажмите **экспортировать ZIP**, чтобы получить `index.html`, `styles.css` и `assets/`;
4. откройте распакованный `index.html` напрямую или загрузите его на статичный хостинг.

## github pages

в репозитории есть workflow `.github/workflows/pages.yml`. после первого пуша откройте в настройках GitHub раздел **Pages**, выберите публикацию через GitHub Actions и дождитесь завершения workflow. сайт будет собираться из корня репозитория без зависимостей и серверной части.

## ограничения и безопасность

Static Studio не подключается к API, не хранит аккаунты и не загружает ваши файлы на сервер. адреса ссылок проверяются перед предпросмотром и экспортом: поддерживаются `https://`, относительные пути и якоря; опасные протоколы блокируются. история изменений хранит последние 50 действий.
