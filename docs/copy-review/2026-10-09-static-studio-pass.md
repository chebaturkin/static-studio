# редакторский проход Static Studio

## что изменилось

- обычные заголовки, кнопки и статусы начинаются со строчной буквы;
- кнопки называют действие: «импортировать проект», «экспортировать ZIP», «добавить блок»;
- ошибки объясняют ограничение и следующий шаг;
- стартовые шаблоны показывают реальный сценарий локальной страницы, без обещаний продаж или охвата;
- README рассказывает путь от открытия файла до публикации на GitHub Pages;
- экспорт, пример и 404 используют одну палитру и одинаковый ритм.

## что сохранено

`Static Studio`, `JSON`, `ZIP`, `HTML`, `GitHub Pages`, URL и ключи данных оставлены в техническом регистре. Ограничения по форматам, размерам и локальному хранению не менялись.

## отдельная проверка

Тексты отредактированы по правилам `chebaturkin-clear-copy` и `chebaturkin-style`: сначала сохранена мысль и факты продукта, затем убраны служебные и рекламные формулировки. Юридические условия и фактическая публикация GitHub Pages требуют проверки уже в подключённом репозитории.
