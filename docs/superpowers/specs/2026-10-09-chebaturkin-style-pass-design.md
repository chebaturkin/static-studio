# Static Studio — проход по голосу и интерфейсу

## цель
Сделать Static Studio понятной локальной мастерской в голосе Тимофея: строчные начала обычных фраз, спокойная конкретика, понятные действия и единый визуальный ритм во всех текстах приложения, экспорта и документации.

## границы
- сохранить бренд `Static Studio` и технические имена (`JSON`, `ZIP`, `HTML`, `GitHub Pages`);
- не менять модель данных и подтверждённые ограничения продукта;
- переписать видимые тексты в `index.html`, `app.js`, `README.md`, `examples/export/index.html` и SVG-метаданных;
- привести UI к тёплой бумажной типографике с более ясной иерархией и доступностью;
- добавить GitHub Pages workflow и 404/metadata, если их нет;
- проверить тесты, статические ссылки, desktop/mobile и reduced motion.

## решения
- первый уровень интерфейса говорит действием: «продолжить», «добавить блок», «сохранить проект»;
- ошибки объясняют, что исправить и какое ограничение действует;
- стартовые шаблоны дают живые, но честные примеры без обещаний результата;
- экспортная страница и README используют тот же голос и палитру;
- GitHub Pages публикует корень репозитория через workflow без сборки.
