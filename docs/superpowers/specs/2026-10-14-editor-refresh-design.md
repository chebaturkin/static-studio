# обновление static studio

основной пользователь: человек, который собирает для себя заметки и небольшие страницы. задача: выбрать основу, написать текст, проверить результат и скачать страницу. текущий запрос разрешает выполнить редизайн и обновить github.

## решения

сохраняем простой редактор без сборки и внешних зависимостей. полная замена на grapesjs дала бы больше инструментов, но усложнила бы личные заметки. косметические изменения оставили бы перегруженную панель. выбираем обновление существующего редактора.

- шапка: знак из двух страниц, название, история, меню проекта, предпросмотр и кнопка «скачать сайт». имя страницы переносим в панель содержания.
- панель: вкладки «содержание» и «оформление». список блоков показывает содержимое. действия доступны у редактируемого блока, без повторения четырёх кнопок в каждой строке.
- старт: заметка и пустая страница, дополнительные шаблоны для портфолио, события и инструкции. создание новой страницы можно отменить.
- предпросмотр: выбор блока нажатием, режимы компьютера и телефона, чистый просмотр. служебные атрибуты и пустые подсказки не попадают в экспорт.
- оформление: три готовые палитры, ширина, цвета, шрифты. настройки страницы не меняют интерфейс редактора.
- сообщения: краткие уведомления после действий, постоянное сообщение только при ошибке. предупреждение, если браузер не сохраняет изменения.
- стиль: строчные подписи и названия сервисов, без длинного тире. интерфейс с мягкими скруглениями, тёплым светлым фоном и зелёным акцентом, обычный читаемый шрифт.
- сохранение: json для продолжения работы, zip для готовой страницы. существующие проекты v1/v2 продолжают открываться.

## проверка

проверить ширины 320, 390, 768, 1024 и 1440 px, клавиатуру, диалоги, выбор блока, добавление, перемещение, копирование, удаление и отмену; загрузку картинки; импорт и экспорт; восстановление после обновления. проверить, что цвета страницы не меняют редактор и что экспорт открывается самостоятельно.

## референс

изучены [grapesjs](https://github.com/GrapesJS/grapesjs) и [block manager](https://grapesjs.com/docs/modules/Blocks.html): раздельные инструменты добавления, структуры и оформления. это ориентир для организации панели; код и зависимость не заимствуются.
