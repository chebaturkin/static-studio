    static studio

    from note to page

    make it yours. choose a block on the left or click it in the preview. text updates as you type. new blocks appear after the current one.

    adjust the design. choose colours, fonts and width in the “design” tab. “view” opens a clean preview.

    keep your work. changes are saved in this browser. choose “project → save project” for a backup. you can open that json here later.

    download your page. “download site” saves a zip. unzip it and open index.html. to publish, upload all files to a static host such as github pages.

    cmd/ctrl + z: undo · shift + cmd/ctrl + z: redo
