    static studio

    от заметки до страницы

    добавьте своё. выберите блок слева или нажмите на него в предпросмотре. текст меняется сразу. новые блоки появляются после текущего.

    настройте вид. во вкладке «оформление» выберите цвета, шрифты и ширину. кнопка «посмотреть» открывает чистый предпросмотр.

    сохраните работу. изменения сохраняются в этом браузере. для резервной копии выберите «проект → сохранить проект». этот json можно открыть здесь позже.

    скачайте страницу. кнопка «скачать сайт» сохранит zip. распакуйте его и откройте index.html. для публикации загрузите все файлы на статичный хостинг, например github pages.

    cmd/ctrl + z: отмена · shift + cmd/ctrl + z: повтор
    alt + ↑/↓: перемещение блока в списке
